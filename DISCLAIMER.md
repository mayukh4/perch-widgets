# What this list is, and is not

**It is a phone book, not a bodyguard.**

- Widgets listed here are **not reviewed for security or quality**. CI
  checks that a listing is well-formed and its links resolve — it does not
  read the code, and neither does the maintainer.
- A Perch widget is compiled into your build and runs with Perch's
  privileges: network access from your Pi, and any secret you give it in
  its own settings. **Read what you install.** The copy-into-`widgets/`
  install exists precisely so that you can.
- Listing is not endorsement. Removal is housekeeping (dead links, archived
  repos), not judgement.
- Bugs in a widget go to the widget's own repo — every listing carries the
  address. Bugs in Perch itself go to
  [perch](https://github.com/mayukh4/perch/issues).
- The maintainer does not arbitrate duplicates. If a widget already does
  what yours does, improving it via PR is usually better for everyone than
  a second listing — but both may exist.
